Was ist NoPaste?

NoPaste ist eine Open-Source-Website ähnlich wie Pastebin, auf der du beliebige Codeausschnitte speichern und Links zum einfachen Teilen erzeugen kannst

Das Besondere an NoPaste ist jedoch, dass es Ohne Datenbank und ohne Backend-Code.e.
Stattdessen werden die Daten komprimiert und vollständig im Link gespeichert, den du teilst – nirgendwo sonst.

Aus diesem Design heraus:

🗑️ Deine Daten können auws NoPaste NICHT gelöscht werden.
🔞 Deine Daten können nicht zensiert werden.
👁️ Der Server, der NoPaste hostet (oder irgendeine Kopie davon), kann deine Daten nicht lesen oder darauf zugreifen.
⏳ Deine Daten sind für immer zugänglich (solange du den Link hast).
🔀 Du kannst auf deine Daten in jedem NoPaste-Clone zugreifen, einschließlich deiner Eigenen.
🔍 Google wird deine Daten nicht indexieren, auch wenn dein Link öffentlich ist.

Wenn du mehr wissen willst, findest du weitere Informationen auf GitHub
Zusatzhinweis: NoPaste ist eine verbesserte Version von Topaz’ Paste
NoPaste kann die URL nicht dekomprimieren
