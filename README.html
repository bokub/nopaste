NoPaste

Was ist NoPaste?

NoPaste ist eine Open-Source-Website ähnlich wie Pastebin, auf der du jeden Code speichern und Links zum einfachen Teilen generieren kannst

Was NoPaste besonders macht, ist, dass es mit keiner Datenbank und keinem Back-End-Code funktioniert. Stattdessen werden die Daten komprimiert und vollständig im Link gespeichert, den du teilst, nirgendwo sonst!

Wegen dieser Gestaltung

- 🗑️ Deine Daten **können nicht gelöscht** werden von NoPaste
- 🔞 Deine Daten **können nicht zensiert** werden
- 👁️ Der Server, der NoPaste hostet (oder einen Klon davon) **kann deine
  Daten nicht lesen oder zugreifen**
- ⏳ Deine Daten sind **für immer** zugänglich (solange du den Link hast)
- 🔀 Du kannst auf deine Daten auf **jedem NoPaste-Klon** zugreifen,
  einschließlich [deinem eigenen](https://github.com/bokub/nopaste/wiki/Deploy-your-own-version-of-NoPaste)
- 🔍 Google wird deine Daten **nicht indexieren**, auch wenn dein Link
  öffentlich ist

Hinweis: Dieses Projekt ist eine Kopie von Topaz's Paste-Dienst, mit überarbeitetem Design und ein paar zusätzlichen Funktionen (Syntax-Highlighting, Zeilennummern, Offline-Nutzung, Einbettung...)

Wie es funktioniert

Wenn du auf "Link generieren" klickst, komprimiert NoPaste den ganzen Text mit dem LZMA-Algorithmus, kodiert ihn in Base64 und fügt ihn in das optionale URL-Fragment nach dem #-Symbol ein: nopaste.boris.sh/#<deine Daten gehen hier hin>

Wenn du einen Link öffnest, liest NoPaste, dekodiert und dekomprimiert das, was nach dem # kommt, und zeigt das Ergebnis im Editor an.

Dieser Prozess wird vollständig in deinem Browser durchgeführt, und der Webserver, der NoPaste hostet, hat nie Zugriff auf das Fragment

Offline-Nutzung

Wenn du NoPaste zum ersten Mal besuchst, wird sein Code in deinem Browser Cache gespeichert. Nach dem Laden alle NoPaste-Links, die du öffnest, werden wirklich schnell geladen, auch wenn deine Internetverbindung langsam ist.

Was ist, wenn du überhaupt keine Internetverbindung hast? Kein Problem, NoPaste funktioniert immer noch perfekt!

Editor-Funktionen

- Syntax-Hervorhebung (verwende den Sprachselektor)
- Zeilenumbruch aktivieren / deaktivieren (verwende die Schaltfläche neben
  dem Sprachselektor)
- Zeile löschen (`Strg+D`)
- Mehrere Cursor (`Strg+Klick`)
- Übliche Tastenkombinationen (`Strg+A`, `Strg+Z`, `Strg+Y`...)

NoPaste-Links generieren

NoPaste-Links können einfach von der Befehlszeile deines Systems erstellt werden:

# Linux
echo -n 'Hello World' | lzma | base64 -w0 | xargs -0 printf "https://nopaste.boris.sh/#%s\n"

# Mac
echo -n 'Hello World' | lzma | base64 | xargs -0 printf "https://nopaste.boris.sh/#%s\n"

# Windows / WSL / Linux
echo -n 'Hello World' | xz --format=lzma | base64 -w0 | \
  printf "https://nopaste.boris.sh/#%s\n" "$(cat -)"
